# EasyApps FAQ
- What is EasyApps?
<br>EasyApps is a Discord bot that lets servers create and manage applications easily.

- How do I apply?
<br>Use the application command "/apply" in the server.

- Can I edit my application after submitting?
<br>No, once submitted, applications cannot be edited. Contact staff if needed.

- How long does it take to get a response?
<br>This depends per server as we dont manage submitted applications for each server. But normally servers respond applications 24h-48h after submitting.
