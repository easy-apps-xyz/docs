# EasyApps FAQ
Welcome to the EasyApps FAQ page. This page is organized into two sections: one for general users and one for server managers.

## General Users
- What is EasyApps?
<br>EasyApps is a Discord bot that lets servers create and manage applications easily.

- How do I apply?
<br>Use the application command "/apply" in the server.

- Can I edit my application after submitting?
<br>No, once submitted, applications cannot be edited. Contact staff if needed.

- How long does it take to get a response?
<br>This depends per server as we dont manage submitted applications for each server. But normally servers respond applications 24h-48h after submitting. For more information we suggest you contact server staff as they are the one´s who manage applications you submit.

- What happens after I apply?
<br>Your application is sent to staff for review. You may receive a role or a response depending on the result.

- Who can see my application?
<br>Only authorized staff members in the server.


## Server Managers
- How do I create an application?
<br>Use the /create_application command. This opens a setup panel where you configure everything. Refer to https://docs.easy-apps.xyz/gettingstarted/setup/ for a more detailed guide.

- What do I need to create an application?
<br>You must set:
<br>-Log Channel (required)
<br>-Application Name
<br>-Application status (open/closed)
<br>-Roles (passed, failed, applied)
<br>-Questions list

- What is the Log Channel?
<br>The channel where submitted applications are sent for staff review.
<br>⚠️ This is required to create an application.

- Can I customize questions?
<br>Yes, EasyApps supports unlimited questions. You can create, edit, remove, and reorder them in the Questions Editing section.

- Can I edit an existing application?
<br>Yes, use /edit_application to reopen the setup panel and make changes.

- How do I remove an application?
<br>Use /remove_application to fully delete it.

- Is there a limit to applications?
<br>No, you can create unlimited applications.
