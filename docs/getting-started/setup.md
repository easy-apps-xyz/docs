# EasyApps Setup Guide

EasyApps is very easy to set up, requiring only a few seconds before you can begin building your applications.

To set up EasyApps, the **server owner** must run the command: `/server_setup`

During this process, you will be asked to provide:

- The **Application Reviewer** role ID
- The **Application Manager** role ID

After submitting the required information, the setup is complete. You can immediately begin creating and managing applications.

:::warning
Only the **server owner** can run the `/server_setup` command.
:::
