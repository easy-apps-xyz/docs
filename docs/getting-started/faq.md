# EasyApps FAQ

Welcome to the EasyApps FAQ page. This page is organized into two sections: one for general users and one for server managers.

## General Users

**What is EasyApps?**  
EasyApps is a Discord bot that lets servers create and manage applications easily.

**How do I apply?**  
Use the application command `/apply` in the server.

**Can I edit my application after submitting?**  
No, once submitted, applications cannot be edited. Contact staff if needed.

**How long does it take to get a response?**  
This depends per server as we don't manage submitted applications for each server. Normally servers respond to applications 24h–48h after submitting. For more information we suggest you contact server staff as they are the ones who manage applications you submit.

**What happens after I apply?**  
Your application is sent to staff for review. You may receive a role or a response depending on the result.

**Who can see my application?**  
Only authorized staff members in the server.

---

## Server Managers

**How do I create an application?**  
Use the `/create_application` command. This opens a setup panel where you configure everything. Refer to the [Setup Guide](/getting-started/setup) for a more detailed guide.

**What do I need to create an application?**  
You must set:
- Log Channel (required)
- Application Name
- Application status (open/closed)
- Roles (passed, failed, applied)
- Questions list

**What is the Log Channel?**  
The channel where submitted applications are sent for staff review.  
:::warning
This is required to create an application.
:::

**Can I customize questions?**  
Yes, EasyApps supports unlimited questions. You can create, edit, remove, and reorder them in the Questions Editing section.

**Can I edit an existing application?**  
Yes, use `/edit_application` to reopen the setup panel and make changes.

**How do I remove an application?**  
Use `/remove_application` to fully delete it.

**Is there a limit to applications?**  
No, you can create unlimited applications.
